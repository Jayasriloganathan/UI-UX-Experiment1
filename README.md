# UI-UX-Experiment1
## Aim:

To explore the fundamentals of UI and UX, differentiate between UI and UX using real-world case studies, understand the relationship between UI and UX in design, and demonstrate various UI/UX design tools.

## Algorithm:

1. Study the basic concepts and principles of UI and UX design.
2. Analyze real-world applications and websites to identify UI and UX elements.
3. Compare UI features such as colors, typography, icons, and layouts with UX features such as usability, accessibility, and user satisfaction.
4. Examine the relationship between UI and UX in the design process.
5. Explore popular UI/UX design tools such as Figma, Adobe XD, Sketch, Balsamiq, and InVision.
6. Create sample wireframes, mockups, and prototypes using the tools.
7. Evaluate the effectiveness of the designs and document the observations.
